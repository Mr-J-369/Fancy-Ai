## Local integration differences

Unused MNN backends, tools, demos, and converters are disabled with MNN_BUILD_*
flags in sd/CMakeLists.txt; no source pruning step is needed. The text-only LLM
object target (demos, HTTP downloads, vision, and audio are not built) is part
of the patch set below.

Two pre-existing LLM correctness patches remain in llm.cpp and sampler.cpp:
prompt-cache reuse compares actual cached token IDs (with upstream's context mutex),
and Min-P uses a threshold relative to the highest probability. They are not in
upstream HEAD. Vulkan queue completion now records failed fence reset, submission, or fence wait
through MNN's existing Runtime::pCurrentStatus, logs the actual VkResult, and stops
copies on that failed runtime. Tensor host-copy results and pipeline completion
propagate that status instead of reporting success. Host format conversion occurs
only after a successful GPU readback. These are local error-handling changes;
they do not change Vulkan kernels, tuning, allocation policy, or retry failed work.
OpenCL conv_2d_int_buf also corrects symmetric INT8 dequantization: signed INT8
weights use zero offset; the -8*scale adjustment belongs only to packed INT4.
All four convolution tiles and their embedded source/hash are updated. Forwarding
Memory_Low to SD1.5 OpenCL exposed this previously unused quantized-convolution path.
Other retained runtime sources match the pinned commit.

#4783's finalized OpenCL buffer/image Winograd budget and overflow handling, and
#4784's memory accounting are now taken directly from upstream, not reapplied.
