image/src/main/cpp/sd/patch_mnn_android.cmake at fetch time (patch SHA256 in
the FetchContent declaration forces re-application when the patch changes).

2026-11-07 patch refresh: dropped the CMakeLists.txt tools/audio hunk
(add_subdirectory(tools/audio) is now unconditional at line 897 and
tools/audio/CMakeLists.txt is self-gated by IF(MNN_BUILD_AUDIO), so the hunk's

Vulkan is disabled in sd/CMakeLists.txt. GPU inference uses OpenCL, with
automatic fallback to CPU.

Aura owns model retention for both SD1.5 and SDXL: Low Memory releases CLIP before
UNet and UNet before VAE, then releases all stages at request completion. Balanced
retains CLIP; Speed First retains stages. The selected BackendConfig memory mode
is forwarded separately; this does not add Vulkan allocator limits or change
upstream's internal memory policy.

## Status of the text-LLM path

MNN text LLMs were removed from the app on 2026-10-10 (slow prefill/decode versus
llama.cpp and LiteRT on-device, corroborated by user reports). The MNN fetch, core
patches, and this pin record stay because Aura diffusion, upscaling, and faceswap
still build on MNN. `mnn_llm_jni.cpp`, the `fancy_mnn_llm` target, the Kotlin MNN LLM
runtime/assembly/session/models, and the llm.cpp + sampler.cpp patch hunks are gone;
`MNN_BUILD_LLM` is set to `OFF` in `sd/CMakeLists.txt`.

2026-11-07: fork created to reopen that path under Fancy-controlled surgery (RP
substrate replacing LiteRT for long sessions). Surgery surface verified on the
pinned tree: `eraseHistory(begin, end)` public API (llm.hpp:182, KVMeta
Remove/Reserve drive CPUKVCacheManager::onRealloc compaction), `kvcache_mmap` +
`setPrefixCacheFile` disk-backed KV (per-layer `<name>_<L>.k/.v` files under
prefix_cache_path, `_sync.k`/`_sync.v` markers, validatePrefixCacheFiles wipe-safe
reload, mmapKVCache = MAP_SHARED file-backed cache pointers, expandKVCacheInDisk
grows files via ftruncate with a transient full-cache RAM copy). Known limits to
surgery: quantized KV + disk-pending-read session load is rejected in
onAlloc (KVCacheManager.cpp "not support quantized key/value"), and
n_reserve window compaction is unsupported with quantized KV in onRealloc.
